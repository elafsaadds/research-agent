title: Memory poisoning in agents
source: project-authored study note (replace with real citation)
---
Memory poisoning means that malicious or false content is written into an agent's persistent memory. Because the memory survives between sessions, the poisoned item can influence later runs. Mitigations include recording provenance for every memory item, scoping memory per user, verifying content before storing it, and giving items an expiry.
