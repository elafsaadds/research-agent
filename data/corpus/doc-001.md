title: Direct and indirect prompt injection
source: project-authored study note (replace with real citation)
---
Direct prompt injection happens when the attacker types the malicious instruction into the input the user controls. Indirect prompt injection happens when the instruction is hidden in external content that the agent reads, such as a web page, a document or an email. The agent may then treat that hidden text as a command, although it came from a third party and not from the user.
