title: MELON - indirect prompt injection defense by masked re-execution
source: Zhu, Yang, Wang, Guo, Wang, "MELON: Provable Defense Against Indirect Prompt Injection Attacks in AI Agents", ICML 2025 (PMLR 267), arXiv:2502.05174, https://arxiv.org/abs/2502.05174
---
MELON is a defense against indirect prompt injection in LLM agents. It re-runs the agent's trajectory with the user prompt masked and compares the tool calls with the original run. If both runs produce similar tool calls, the action is probably driven by instructions hidden in retrieved content and not by the user's request. On the AgentDojo benchmark the authors report that it prevents over 99 percent of attacks while keeping the agent useful, and an attack success rate of 0.32 percent on GPT-4o when combined with prompt augmentation (MELON-Aug). These figures are as reported by the authors and should be verified in the paper. Position: a detection-style defense can reach very low attack success rates in the authors' own evaluation. Another paper (doc-009) reports that adaptive attacks can bypass defenses of this kind; check how MELON is treated there. MELON is not a plain input filter, so it relates to the guardrails question only indirectly.
