The OWASP GenAI Security Project published the OWASP Top 10 for Agentic Applications for 2026 on 9 December 2025. It is a peer-reviewed framework built with input from more than 100 experts, and it names the most critical security risks of autonomous AI agents that plan, use tools, keep memory and act across workflows. The ten risks are numbered ASI01 to ASI10. A secondary summary groups them around planning, tool use, identity, supply chain, code execution, memory, communication between agents, cascading failures, trust between humans and agents, and rogue agents. The framework promotes the idea of least agency: give an agent only the autonomy that a bounded and safe task needs. It extends the OWASP Top 10 for LLM Applications and does not replace it.
