title: Least privilege for agent tools
source: project-authored study note (replace with real citation)
---
The principle of least privilege says that an agent should receive only the permissions it needs for its task. For tool-using agents this means narrow tools, separate credentials per tool or role, and no general-purpose production credential. The model must never be able to raise its own authority, so permission checks live in application code and not in the prompt.
